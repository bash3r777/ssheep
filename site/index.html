ssheep

Every machine you own, wherever it is — a laptop, a VPS, a box under a desk — in one flock. No open ports, no account, and not one server you have to trust.

Download Source

What you get

  • 🐑Every machine you own, in one flock, whatever network each one is on
  • 🔓No open ports, no port forwarding, no public IP on the machines you manage
  • 🔑One key to keep. It signs who is in — and never has to be online
  • 🙈The relay forwards ciphertext it cannot read, forge, or open
  • 📡Any reachable machine can be a connector, and losing one costs you nothing
  • 🧰One static binary, no dependencies, nothing to install alongside it

Use — three steps

ssheep — set up a flock
step 1  on the machine you control from:
$ ssheep master
👑  master ready — flock "myflock"
    connectors  relay.ssheep.xyz:7000

    run this on each machine you want in the flock:
      ssheep sheep "H4sIAAAA…"
    run this on the machine with a public address:
      ssheep connector "H4sIAAAA…"

step 2  paste that, on each machine:
$ ssheep sheep "H4sIAAAA…"
🐑  this machine is in the flock

step 3  back on the master:
$ ssheep run --all -- uptime
sheep-1|  14:22:01 up 3 days,  2:14,  load average: 0.08
sheep-2|  14:22:01 up 12 days, 4:02,  load average: 0.31
❯

That is the whole setup. The connector works out its own address and tells the flock, so there is nothing to copy between machines but the ticket itself.

How it fits together

The master and the sheep both dial out to a connector; nothing on them ever listens. A connector checks that each machine holds the key the roster says it holds, then forwards opaque payloads between them — it can see who is talking, never what about.
