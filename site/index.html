  • 🐑Every machine you own, one flock
  • 🚀Run a command on every sheep at once
  • 👀See every machine, live, in one screen
  • 🔓No open ports, no port forwarding
  • 🔑One key per flock, and it stays offline
  • 🙈Connector cannot read a thing
  • 🔒Commands and their output are encrypted end to end

  • 🧰One static binary, no dependencies
