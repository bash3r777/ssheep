🐑 SSHeep 🐑

Command your flock!

Download Source
  • 🐑Every machine you own, one flock
  • 🚀Run a command on every sheep at once
  • 👀See every machine, live, in one screen
  • 🔓No open ports, no port forwarding
  • 🔑One key per flock, and it stays offline
  • 👑More than one master, so the key is never alone
  • 🙈The relay cannot read a thing
  • 🗂Many flocks, and a machine can be in several
  • 📡Any reachable machine can be the connector
  • 🛟More than one connector: losing one costs nothing
  • 🚫Revoke a machine, and it is out in seconds
  • 🧰One static binary, no dependencies
  • 📴The flock is a file — no server to maintain

# Create the Flock:
$ ssheep master flock "myflock"
    👑  You are Master — flock "myflock" created

    🐑 run this on each machine you want to be a Sheep 🐑:
      curl -fsSL https://ssheep.xyz/install.sh | sh -s -- --ticket "H4sIAAAA…"

    📡 run this on each machine you want to be a Connector 📡:
      curl -fsSL https://ssheep.xyz/install.sh | sh -s -- --ticket "JSDFndSD…"

    👑 run this on each machine you want to be a Master 👑:
      curl -fsSL https://ssheep.xyz/install.sh | sh -s -- --ticket "LLIfeDDd…"

How it fits together

  • master — holds the key, and there can be more than one
  • connector — a blind relay; the only machine that must be reachable
  • dashed line — one machine, in both flocks
  • pi
  • nas — in both
  • laptop — in both
  • tv
  • router
  • vps
  • phone
  • tablet
  • printer

master → connector → sheep. Commands and their output are encrypted end to end, so a connector carries them without being able to read them.
