🐑 SSHeep 🐑

Every machine you own, wherever it is — a laptop, a VPS, a box under a desk — in one flock. No open ports, no account, and not one server you have to trust.

Download Source

Features

  • 🐑Every machine you own, one flock
  • 🔓No open ports, no port forwarding
  • 🔑One key per flock, and it stays offline
  • 🙈The relay cannot read a thing
  • 🗂Many flocks, and a machine can be in several
  • 📡Any reachable machine can be the connector
  • 🚫Revoke a machine with one command
  • 🧰One static binary, no dependencies
ssheep
step 1  Install SSHeep:
curl -fsSL https://ssheep.xyz/install.sh | sh

step 2  Create the Master 👑:
$ ssheep master flock "myflock"
    👑  master ready — flock "myflock" created

    🐑 run this on each machine you want to be a Sheep 🐑:
      curl -fsSL https://ssheep.xyz/install.sh | sh && ssheep sheep "H4sIAAAA…"

    📡 run this on each machine you want to be a Connector 📡:
      curl -fsSL https://ssheep.xyz/install.sh | sh && ssheep connector "H4sIAAAA…"

step 3  Command the flock:
$ ssheep run "myflock" -- uptime
sheep-1|  14:22:01 up 3 days,  2:14,  load average: 0.08
sheep-2|  14:22:01 up 12 days, 4:02,  load average: 0.31
❯

How it fits together

  • 🚀run a command on every sheep at once
  • 👀see every machine, live, in one screen
  • 🚫revoke a machine, and it is out in seconds
  • 🗂as many flocks as you like, on the same machine
  • 🛟more than one connector: losing one costs nothing
  • 📴the flock is a file — no server to maintain
